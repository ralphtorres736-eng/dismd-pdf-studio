Design Mode Prompt
Redesign the UI for a legal-grade PDF editing assistant called "PDF Assistant."

What it does: Attorneys upload privileged PDFs, then either chat with AI in plain English ("delete pages 3–5 from Exhibit A") or use manual controls (merge, split, delete pages, rotate, highlight). All processing is private — documents never leave the server.

Current layout to redesign (keep the same 3-column structure, upgrade everything else):

Left sidebar — drag-drop upload zone, document list with file names, page thumbnail strip below
Center/right main area — tabbed panel: "AI Chat" tab (chat bubbles, message input) and "Manual Controls" tab (action buttons: delete pages, rotate, split, merge, rename)
Top navbar — app name + "Clear Session" button
Bottom bar — "Download All" and "Download Selected" buttons
Design direction — Legal Dark Professional:

Color palette: deep charcoal #1A1A2E background, midnight navy sidebar #16213E, rich gold accent #C9A84C, white text, subtle slate dividers
Typography: Inter or IBM Plex Sans — clean, readable at small sizes, no serifs
The upload zone should feel like a secure vault drop — dark with a gold dashed border and a lock/shield icon, not a generic dashed box
Document list items should look like file folders in a case management system — each with a document icon, file name truncated with ellipsis, page count badge
Page thumbnails should be cards with a subtle shadow, active/selected state with a gold border ring
AI chat bubbles: user messages right-aligned in gold/amber, assistant messages left-aligned in a dark card with a small "AI" badge — include a "Privacy Protected" indicator in the chat footer ("Your document content is never sent to AI")
Manual Controls tab: group actions into labeled sections (Page Actions, Document Actions), use icon+label buttons with a dark card background, hover state lifts with gold border
Navbar: solid charcoal with the PDF Assistant wordmark left, a gold shield/lock icon next to it, "Clear Session" as a subtle ghost button right
Download buttons: gold primary ("Download All"), ghost secondary ("Download Selected")
All interactive states — hover, active, loading — should feel deliberate and premium
Key UX rules to preserve:

Two-panel layout (sidebar left, main right) — do not collapse into a single panel on desktop
Tab switching between AI Chat and Manual Controls stays in the same right panel
The privacy notice ("document content is never sent to AI") must remain visible in the chat area
Loading states on buttons when operations are running
Deliver: A full redesign of artifacts/api-server/app/static/index.html — the entire HTML/CSS/JS file, self-contained with Tailwind CDN and any Google Font import. No React, no build step. The JS logic for all API calls must stay intact — only the markup and styling should change.
