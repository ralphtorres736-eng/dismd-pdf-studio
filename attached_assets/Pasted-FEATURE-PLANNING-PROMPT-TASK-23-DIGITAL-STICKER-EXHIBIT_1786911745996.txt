FEATURE PLANNING PROMPT — TASK #23: DIGITAL STICKER & EXHIBIT STAMP OVERLAY ENGINE

We want to plan Task #23 to allow users to apply digital sticker and tab overlays directly onto PDF pages via natural language chat. The implementation must use native PyMuPDF (`fitz`) vector drawing (`draw_rect`, `insert_textbox`) and image overlay functions (`insert_image`) without adding heavy third-party dependencies or breaking existing features.

### 1. ACTION SCHEMA EXTENSION
Add a new action type `ADD_STICKER` to `ai_parser.py` with the following parameters:
- `file_name`: target PDF document in session memory.
- `page_numbers`: list of page numbers to apply sticker (default: [1]).
- `category`: string enum ["legal_exhibit", "status_stamp", "novelty"].
- `preset`: 
  * Legal Exhibit presets: "PLAINTIFF" (yellow), "DEFENDANT" (blue), "PETITIONER" (orange), "RESPONDENT" (teal), "EXHIBIT" (white).
  * Status presets: "CONFIDENTIAL" (red border), "URGENT / TIME SENSITIVE" (red banner), "DRAFT" (gray watermark outline).
  * Novelty / Funny presets: "BORN TO ARGUE", "LIVE LAUGH LAWSUIT", "BILLING YOU FOR THIS", "OBJECTION!", "JUSTICE SERVED".
- `custom_text`: optional custom secondary text (e.g., "EXHIBIT A", "NO. 123", "FOR ATTORNEY EYES ONLY").
- `position`: string enum ["top-left", "top-right", "bottom-left", "bottom-right", "center"] (default: "bottom-right").
- `rotation`: optional float rotation angle in degrees (default: 0; allow slight tilt like -5 to +5 for a realistic sticker feel on novelty stamps).

### 2. BACKEND IMPLEMENTATION (pdf_ops.py)
Create `apply_sticker(doc, page_num, sticker_config)`:
- For Legal Exhibits:
  * Draw a rounded vector rectangle (`draw_rect`) with preset fill colors matching physical legal tabs (e.g., Yellow `#FDE047`, Light Blue `#38BDF8`, Orange `#FB923C`, Teal `#2DD4BF`, White `#FFFFFF`).
  * Add a crisp black outline and render bold header text (e.g., "PLAINTIFF'S EXHIBIT") above the underline, followed by `custom_text` (e.g., "EXHIBIT A").
- For Status Stamps:
  * Render framed status boxes or diagonal watermark stamps (e.g., red "CONFIDENTIAL" border).
- For Novelty / Graphic Stickers:
  * Support vector text badge rendering with playful fonts/borders, or optional local PNG badge assets stored in `static/stickers/` if raster rendering is desired.

### 3. ACTION DISPATCHER & PREVIEW (main.py & JS Frontend)
- Thread `ADD_STICKER` through `main.py` action dispatcher.
- Ensure modified pages save back to session memory and immediately reload in the Page Preview pane so the attorney can visually verify sticker placement.

Please generate a detailed execution plan covering all modified files (`ai_parser.py`, `pdf_ops.py`, `main.py`), edge cases (page boundaries, overlapping text), and test prompts before switching to Build mode.
